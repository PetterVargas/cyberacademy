El Curso de Desarrollo Seguro hace parte de la learning path de CyberUsuario, realizamos esta descripción para dar un 
mapa mental de que vamos logrando y cómo todo hace parte de un ecosistema focalizado en la mejora continua.

Este es uno de nuestros espacios más técnicos en la learning path de CyberUsuario, y está enfocado para cualquier persona que 
tiene relación directa o indirecta con código o el desarrollo de software; pero, sólo desde la óptica de antipación como colaborador, 
existen otros cursos en nuestra learning path de CyberGuardián para proteger el ciclo de desarrollo de software SDLC en términos de gestión 
y gobernanza. Acá es para llegar mucho antes de los controles del Security SDLC, es realmente qué puedo realizar yo en ciberseguridad como 
desarrollador en mi equipo antes de enviar mis cambios a una rama remota.
