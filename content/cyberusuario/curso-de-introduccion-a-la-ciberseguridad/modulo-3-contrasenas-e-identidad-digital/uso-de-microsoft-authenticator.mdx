---
title: Uso de Microsoft Authenticator
description: Cómo usar Microsoft Authenticator
---

Microsoft Authenticator funciona de forma similar a otras apps de autenticación, generando códigos temporales de un solo uso, pero además ofrece inicio de sesión sin contraseña mediante notificaciones push para cuentas de Microsoft: en lugar de escribir una clave, el usuario simplemente aprueba la solicitud directamente desde el celular. También permite guardar contraseñas de otros sitios y sincronizarlas de forma cifrada entre dispositivos vinculados a la misma cuenta. Es especialmente útil en entornos donde ya se usan servicios de Microsoft como Outlook o Microsoft 365, ya que su integración resulta más directa que la de apps de terceros. Como con cualquier segundo factor, conviene guardar los códigos de recuperación proporcionados al activarlo, para no quedar bloqueado fuera de las cuentas si se pierde el acceso al celular.
